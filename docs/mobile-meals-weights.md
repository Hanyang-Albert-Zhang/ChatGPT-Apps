
# Mobile diary and conversation workflow
Saved meals are remembered with name, calorie/carbohydrate/protein/fiber/fat values and original description. A meal mutation and template update run in one D1 batch. Names are normalized for per-user deduplication. A private query merges old meal history with templates, so existing foods are available immediately. Choosing a suggestion reuses original-portion macros without another external lookup. Photos are not copied into templates.
Inbox displays only friends, challenge overview, invitations and conversation list. Clicking a conversation synchronously opens a separate browser tab with #Conversation?thread=... . The standalone route contains conversation features and a persistent Back to Inbox button beside the name. Popup-blocked browsers fall back to the dedicated route in the same tab. Unread counts come from server lastReadAt and render red numbered circles; visiting Inbox no longer loads hidden conversations or marks them read. Group icons are available in both existing-friend creation and the New Chat group form.
Mobile left/right gestures traverse Home, Food, Train, Inbox, Progress, Trophies without wrapping. Rightward goes to the previous page, leftward to the next. Vertical pull down from the top refreshes the whole site. Forms, buttons, links, dialogs, horizontally scrolling charts/tables, message scrolling and history lists do not trigger gestures. Multi-touch and diagonal/short gestures are ignored. Gesture logic is unit tested; physical iPhone browser touch input requires device testing.
Daily morning check-ins use one owned server-date record per Eastern day, stored in kg and displayed in kg/lb. Saving again corrects today. Weight trends use a seven-day mean and least-squares 28-day slope. No automatic profile, calorie-goal or historical log mutation occurs.
The app-defined wellness index now weights movement25/strength15/fiber15/protein15/energy10/weight-goal trend20. A grade needs saved profile, ≥14 food days, exercise, ≥7 weights spanning ≥14 days, and ≥2 waist weeks. Weight-goal slope scoring is explicitly a product formula and not a clinical measure. BMI/body-fat estimates use seven-day average weight; waist-to-height uses up to three recent weekly waist measures. All body measurement trends are visible; shrinking a body part is not automatically rewarded.
Downloaded nutrition HTML is a self-contained visual report with summary cards, SVG charts/target references, macro detail tables, meal cards, and embedded meal photos. It needs no network to display its data. User text is escaped.

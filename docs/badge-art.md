# Badge artwork

The original 20 badge illustrations and first-workout illustration use the two images supplied by the user. They are rendered as clipped sprites, with names, levels and requirements in accessible HTML so incorrect embedded reference captions do not become badge rules.

The new illustration sheet is `public/badges/new-badges.png`, created using the built-in image generation tool. It contains 30 distinct cells in a six-column, five-row grid. No Apple, Garmin or Strava branding or artwork is copied.

Badge goals take general inspiration from official achievement systems:

- https://support.apple.com/guide/watch/apd3bf6d85a6/watchos
- https://support.garmin.com/en-GB/?faq=6pECo6UIFn7ergw8kNmfu9
- https://support.strava.com/en-us/articles/15401916-strava-challenges

All badge eligibility uses FitDiet logs. The exact catalog distribution is 20/10/10/5/5, with rewards of 200/600/1,500/3,000/8,000 XP. Existing badge IDs and thresholds are retained.
